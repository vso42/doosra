doosra lists, for every pair liqind routes, roughly how much you can sell before the price slips 1, 2, 3, 5 or 10 percent, grouped by chain. The numbers come from our own router run against a saved block on each chain, so they are model estimates rather than executed trades. The page is plain HTML: `build.py` reads the input files in `data/`, which are not in this repo, and writes `docs/`, which GitHub Pages serves at https://vso42.github.io/doosra/. The numbers shown on the page are also in `docs/data/figures.json`.

The current publication uses confirmed newer numerical results only. Older, imported and audit-only quotes are removed from the active inputs; a missing newer result stays blank. Saved capture and research files remain available for reproducibility. From the project root, run `.venv-dexrouter/bin/python scripts/publish_integrity_corrections_site.py --publish` to rebuild the reviewed publication, then push `site/docs/`. This includes the three quantity-funded recovery corrections, the PYUSD → GHO captured converter-bridge correction, four strict input-domain repairs and an unchanged-output integer bookkeeping repair. The obsolete PYUSD → GHO quote set is removed from the active dataset. The local publication policy makes `build.py` reject older solver inputs. Earlier exporters are reproducibility artifacts and do not include these later corrections.

The full catalogue audit and rerun are recorded separately in `investigations/all-pair-integrity-20261019/`; this publication does not claim that work is complete. These are funded model estimates with recorded pool-coverage and optimality limits, not whole-route execution proofs.
