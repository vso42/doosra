doosra lists, for every pair liqind routes, roughly how much you can sell before the price slips 1, 2, 3, 5 or 10 percent, grouped by chain. The numbers come from our own router run against a saved block on each chain, so they are model estimates rather than executed trades. The page is plain HTML: `build.py` reads the input files in `data/`, which are not in this repo, and writes `docs/`, which GitHub Pages serves at https://vso42.github.io/doosra/. The numbers shown on the page are also in `docs/data/figures.json`.
